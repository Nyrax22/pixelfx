# 던전이 살아있다

살아 있는 던전의 심장이 되어 방어 카드를 고르고 배치해 침입자를 막아내는 역(逆)던전 로그라이트.
기획서(2026-11-21)의 핵심 루프를 처음부터 끝까지 플레이할 수 있게 만든 프로토타입이다. 모든 이펙트와
몬스터는 이 저장소의 pixelfx 코드로 그려지고, 소리는 전부 WebAudio로 합성한다. 이미지·음원 파일은 없다.

## 실행

```bash
npm install                          # esbuild
node games/dungeon-alive/build.mjs   # dist/index.html 한 파일로 묶는다 (약 375 KB)
```

`games/dungeon-alive/dist/index.html`을 브라우저로 열면 된다. 서버가 필요 없다. 수정하면서 보려면
`--watch`를 붙인다. 주소 끝에 `?skipprologue`를 붙이면 프롤로그를 건너뛴다(테스트용).

## 들어간 것

| 기획서 | 구현 |
|---|---|
| 프롤로그 (봉인되던 날) | 타이틀 없이 시작. 전성기 카드 3장으로 기사단을 쓸어버리고, 재상의 거짓 명령, 봉인 마법사, 발동하지 않는 카드, 심연의 눈, "백 년 후". 다시 볼 때는 건너뛰기 가능 |
| 카드 선택형 디펜스 | 밤 시작과 웨이브마다 3장 중 1장. 함정 6 · 방어 시설 5 · 몬스터 9 · 마법 4 · 회복·강화 2 |
| 방 드래프트 | 낮마다 3장 중 1장. 통로를 바꾸거나 바위를 파서 붙인다. 물+번개, 용암+불, 버섯+독 같은 인접 시너지 |
| 비밀 방 | 봉인된 문, 그리고 정해진 방 조합(물+용암, 서고+제단, 둥지+보물, 어둠+얼음)이 핵심 기록을 연다 |
| 몬스터 교배 | 부모 특성을 하나씩 물려받고 낮은 확률로 돌연변이(무지개 테두리와 팡파르). 이름 짓기, 계보가 판을 넘어 남고 ★ 몬스터가 다음 판에 따라온다 |
| 모험가 | 전사·도적·마법사·성직자. 보물을 쫓고, 길드가 아는 방은 피하고, 겁먹으면 도망간다. 도적은 함정을 해제하고 성직자는 치료한다 |
| 살려 보내기 / 끝장내기 | 도망치는 모험가마다 선택. 살아 나간 자는 길드에 알려 다음 파티가 대응 장비(고무 장화, 화염 저항 망토…)를 들고 온다. 선술집 소문으로 미리 보인다. 숙적이 되어 돌아오기도 한다 |
| 힘 되찾기 | 이기든 지든 영혼. 힘 20개를 순서대로 되찾는다. 화폐는 영혼 하나 |
| 첫 6분 | 첫 판은 3일. 둘째 날 물이 찬 방과 번개 함정, 첫 교배는 확정 돌연변이(왕관 쓴 격하게 겁 많은 슬라임), 셋째 날 봉인된 문. 심장은 아슬아슬하게 버틴다 |
| 일기 | 모험가마다 이름·고향·사연이 생성되고, 쓰러지면 일기가 떨어진다. 핵심 기록 10편 (1~2막) |
| 화면 | 숨 쉬는 벽, 심장 박동에 맞춰 빛나는 바닥 틈, 체력이 줄면 빨라지는 심장, 밤의 어둠과 횃불, 피 대신 별과 동전, 화난 유령, 연쇄 표시, "던전 털림" 도장 |
| 저장 | 기기 로컬, 3슬롯 번갈아 쓰기 + 체크섬, 낮마다 자동 저장, 내보내기/가져오기 |
| PC·모바일 | 가로 화면, 세로 화면(위 맵 · 아래 카드), 탭 한 번 선택 · 탭 한 번 배치 |

숫자는 전부 `data/*.json`에 있다(카드, 방, 밸런스, 힘, 몬스터, 이야기). 코드는 그대로 두고 숫자만 고쳐서
밸런스를 맞춘다.

## 아직 없는 것

- 2·3막 후반 콘텐츠, 최종전, 엔딩 3종 (힘 20개를 되찾으면 "심연이 꿈틀거린다"에서 멈춘다)
- 패배 후 3초 리플레이 (지금은 가장 많이 뚫린 방을 표시한다)
- Electron / Capacitor 포장

## 구조

```
data/        카드 · 방 · 밸런스 · 힘 · 몬스터 · 이야기 (JSON)
src/sim.js   규칙. DOM 없음. 이벤트를 run.events에 쌓는다
src/render.js 캔버스: 방, 몬스터(pixelfx critters), 모험가, 이펙트(pixelfx), 밤 조명
src/sprites.js 코드로 그린 픽셀 스프라이트: 모험가, 카드 아이콘, 심장
src/main.js  화면 흐름과 UI
src/prologue.js 프롤로그 연출
src/audio.js 합성 효과음과 음악
test/        화면 없이 수백 판을 돌리는 봇 (밸런스 시뮬레이터)
```

```bash
node games/dungeon-alive/test/run.mjs 200   # 200판: 오류, 승률, 밤 길이, 힘 단계별 생존일
```
