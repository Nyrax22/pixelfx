## 1. 한 줄 요약

**동굴에 갇혔다. 배고픔·목마름·빛을 관리하며 300m 아래 출구까지 살아서 내려가라.**

옆에서 보는 2D 픽셀아트 **자원 관리 생존 + 동굴 탐험** 게임입니다. 런을 반복하며 유물을 모아 도감을 채우고, 코인으로 영구 업그레이드를 사서 더 깊이 내려갑니다.

- 1차 목표 플랫폼: **Poki** (웹)
- 반응이 좋으면 다음 단계: **Google Play → Steam**
  - Poki 웹 독점은 *웹에만* 적용됩니다. 앱스토어와 Steam 출시는 허용되며, 독점 기간은 기본 7년입니다.

## 2. 핵심 루프

```
동굴 진입 → 자원 채집·제작으로 생존 → 유물·코인 획득 → 출구 도달 or 사망
   ↑                                                        ↓
   └──── 업그레이드 구매 ← 도감 등록·세트 보너스 ← 결과 화면 ───┘
```

- 죽어도 이번 런에서 모은 **코인과 유물은 그대로 유지**됩니다. 손해 없이 "한 판만 더" 하게 만드는 구조입니다.
- 결과 화면에는 도달 깊이, 생존 시간, 획득 유물이 나옵니다.

## 3. 생존 시스템

### 게이지 3개
| 게이지 | 줄어드는 방식 | 0이 되면 |
|---|---|---|
| 🍄 배고픔 | 시간이 지나면 감소 | 5초마다 하트 −1 |
| 💧 목마름 | 시간이 지나면 감소 (배고픔보다 빠름) | 5초마다 하트 −1 |
| 🔦 빛 | 랜턴 연료가 감소 | 화면이 어두워지고 괴물이 몰려옴 |

### 자원
| 자원 | 얻는 곳 | 용도 |
|---|---|---|
| 버섯 | 바닥에 자람, 보급 상자 | 먹기 (+35, 모닥불 옆에서 구우면 +60) |
| 물 | 물웅덩이 위에 서 있기 (웅덩이는 다시 차오름) | 마시기 (+40) |
| 기름병 | 바닥에서 줍기 | 빛 즉시 +45 |
| 나무 | 천장 뿌리(점프로 닿기), 보급 상자, 나무판자 캐기 | 횃불, 모닥불, 로프 |
| 돌 | 돌·보석·벽돌 캐기 | 모닥불 |

### 제작
| 키 | 제작물 | 재료 | 효과 |
|---|---|---|---|
| 3 / T | 횃불 | 나무 2 | 고정 광원. 빛 안으로 괴물이 잘 들어오지 못함 |
| 4 / F | 모닥불 | 나무 3 + 돌 3 | 체력 회복, 빛 충전, 버섯 굽기 |
| X / C | 로프 | 나무 2 | 구덩이 탈출 |

### 어둠과 괴물
- 빛이 약할수록 화면 밖에서 박쥐와 해골이 출몰하고, 빛이 0이면 더 자주 나옵니다. 동시에 나올 수 있는 수에는 상한이 있습니다.
- 박쥐는 빛을 피하고, 해골은 빛 속의 플레이어에게 돌진하지 않으며, 슬라임은 빛의 경계에서 돌아섭니다.

## 4. 동굴과 구역

- 크기: 가로 48 × 세로 306 타일이며, 1타일 = 1m입니다. 화면은 480×270 픽셀이고 타일은 16px입니다.
- 셀룰러 오토마타로 매번 새로 생성됩니다. 생성되는 것:
  - 사다리가 놓인 메인 경로와 옆길
  - 방(벽돌·나무)과 광석
  - 보스 아레나
- 시작 방에는 항상 버섯 2, 물웅덩이 1, 기름병 1, 보급 상자 1이 있습니다.

| 구역 | 깊이 | 특징 |
|---|---|---|
| 마을 폐허 | 0–100m | 자원이 비교적 넉넉함 (버섯 15, 뿌리 30). 보스: **슬라임 킹** (88–98m, HP 4) |
| 광산 | 100–300m | 자원이 부족함 (버섯 7, 뿌리 10). 보스: **고대 골렘** (189–199m, HP 5) |
| 출구 | 296m | 도달하면 탈출 성공 |

- 위험 요소: 박쥐, 슬라임, 빨간 슬라임, 해골, 가시, 떨어지는 종유석, 낙하 피해
- 지름길 출발(top / mine / deep): 해당 지점에서 모닥불을 켠 채로 시작합니다.

## 5. 조작

| 행동 | 키보드 | 모바일 |
|---|---|---|
| 이동·사다리 | ←→↑↓ / WASD | 가상 스틱 |
| 점프 | Space / Z | 점프 버튼 |
| 캐기 | 벽으로 밀기, ↓ 길게 누르기 | 스틱 방향 유지 |
| 먹기 / 마시기 | 1(E) / 2(Q) | 생존 바 버튼 |
| 횃불 / 모닥불 | 3(T) / 4(F) | 생존 바 버튼 |
| 로프 | X / C / R | 생존 바 버튼 |

- 생존 바에서는 지금 쓸 수 있는 버튼만 밝게 표시됩니다. 필요한 순간에는 해당 버튼이 깜빡입니다 (예: 배고픈데 버섯이 있을 때).
- 상황별 안내: 배고픔, 목마름, 빛 부족, 어둠, 굶주림, 웅덩이, 뿌리, 모닥불 상황을 처음 만나면 노란 안내가 한 번씩 뜹니다. 본 안내는 저장됩니다.
- 물리 보정: 코요테 타임, 점프 입력 버퍼, 사다리 꼭대기 자동 올라서기, 넉넉한 밟기 판정

## 5-1. 설계된 방과 함정 (2026-11-18, Spelunky식)
- **동굴 구조:** 무작위 노이즈 동굴 대신, 직접 설계한 12×8칸 방을 가로 4칸 격자로 쌓아요. 템플릿은 `src/rooms.js`에 있어요.
  - 길 방 12종: 가시 구덩이, 화살 복도, 무너지는 다리, TNT 홀, 기둥 방, 금맥, 버섯 정원, 오두막 등
  - 옆방 9종: 벽돌로 막힌 금고, 황금 우상 방, 항아리 창고, 박쥐 굴, 금맥 바위, 화약 창고, 샘, 무너진 통로, 화살 회랑
  - 칸 일부는 무작위이고, 방마다 50% 확률로 좌우가 뒤집혀서 매번 달라요.
  - 길은 방을 따라 옆으로 이동하다 사다리로 내려가요. 막힌 옆방 중 길 옆에 붙은 방은 금 간 벽을 가진 비밀의 방이 돼요.
- **폭탄 (B 키 / 폭탄 버튼):** 처음 3개를 들고 시작해요.
  - 던지면 1.6초 뒤 터지고, 아래를 누른 채 쓰면 발밑에 놓아요.
  - 반경 안의 벽(기반암 제외), 몬스터, 보스, 항아리를 날리고, TNT는 연쇄로 터져요. 나도 피해를 받아요.
  - 보급 상자(40%)와 상인(20코인에 2개)에서 얻어요.
- **함정과 장치:**
  - 화살 함정: 앞을 지나가면 철컥 소리와 함께 0.16초 뒤 화살이 날아오고, 4초 뒤 다시 장전돼요. 몬스터와 TNT도 맞아요.
  - 무너지는 발판: 밟으면 0.5초 뒤 떨어져요.
  - 황금 우상: 가지면 코인이 쏟아지지만, 반대편에서 거대한 바위가 굴러와요.
  - TNT 통: 곡괭이·화살·폭발에 맞으면 잠시 뒤 터져요.
- **안전장치:** 생성 후 입구에서 출구까지 길이 이어지는지 확인하고, 막혔으면 길 방을 따라 통로를 뚫어요. 80개 동굴로 검사했는데, 의도한 무너진 통로 말고는 모두 출구까지 이어졌어요.

## 6-0. 탐험의 신비 (2026-11-17 추가)
- **미지의 어둠 (전장의 안개):**
  - 직접 가서 랜턴 빛이 닿은 곳만 보여요. 벽 너머는 가 보기 전까지 완전히 검은색이에요.
  - 모퉁이 너머의 보물·몬스터·이벤트도 그 전엔 보이지 않아요.
  - 설치한 횃불·모닥불 주변도 밝혀져요.
- **미니맵:** 왼쪽에 탐험한 곳만 그려지는 지도가 있어요.
  - 보물상자, 이벤트, 석판, 봉인된 유물이 점으로 표시돼요.
  - 붕괴가 시작되면 붕괴 구역이 빨갛게 표시돼요.
- **비밀의 방:** 동굴마다 2~4개씩 있어요.
  - 금 간 벽 틈으로 먼지가 새어 나오는 게 단서예요. 금 간 벽은 곡괭이 내구도를 쓰지 않고 금방 깨져요.
  - 안에는 좋은 보물상자와 석판이 있어요.
- **고대의 석판:** 이야기 조각 12개가 있어요.
  - 하람 마을이 왜 땅속으로 가라앉았는지, 심장석, 수호자 골렘, 맨 아래의 문에 관한 이야기예요.
  - 읽은 조각은 거점의 '이야기' 탭에 쌓여요.
- **살아 있는 동굴:**
  - 소품: 항아리(곡괭이로 깨면 코인·버섯·물·기름·내구도), 해골, 덩굴, 거미, 광차, 화석.
  - 빛나는 것: 버섯과 수정이 제각각 다른 색으로 빛나요.
  - 작은 생물: 딱정벌레, 달팽이, 게, 도마뱀이 돌아다니다가 가까이 가면 도망가요.
- **명소:** 구역마다 하나씩 나와요.
  - 마을: 빛나는 버섯 동굴, 잊힌 묘지
  - 광산: 버려진 광부 야영지, 거대한 뼈 무덤, 수정 동굴
- **봉인된 유물 (선택):**
  - 215m 아래 받침대에 있어요. 꺼내면 보상이 2배가 되지만, 그 순간 동굴이 무너지기 시작해요. 출구까지 달리는 마지막 승부예요.
  - 꺼내지 않으면 붕괴가 없어서 마음껏 탐험할 수 있어요.

## 6-1. 긴장감 (2026-11-17 추가)
> 붕괴는 이제 봉인된 유물을 꺼냈을 때만 시작돼요.
- **무너지는 동굴:** 탐험을 시작하고 18초 뒤부터 위에서 바위 벽이 내려와요. 처음 몇 판은 33초 뒤부터예요.
  - 점점 빨라져서, 초당 0.32m로 시작해 최고 0.66m까지 올라가요. 내가 너무 앞서가면 따라잡으려고 더 빨라지고, 보스전 중에는 멈춰요.
  - 바로 위까지 오면 경고와 함께 돌이 떨어지고, 붕괴에 닿으면 0.7초마다 하트가 하나씩 깎여요.
  - 화면 위쪽 경고와 깊이 게이지의 붉은 띠로 붕괴 위치가 보여요.
- **곡괭이 내구도:** 처음 30이고, 곡괭이 업그레이드로 늘어나요. 흙 1, 돌·벽돌 2씩 닳아요.
  - 보급 상자 +5, 보물상자 +8, 상인 수리(15코인) +12로 회복해요. 0이 되면 팔 수 없어요.
- **곡괭이 공격:** X 키 또는 모바일 공격 버튼으로 앞쪽을 휘둘러요. 몬스터와 보스에게 모두 통해요.
- **벽 미끄러지기·벽차기:** 공중에서 벽 쪽으로 누르면 천천히 미끄러지고 낙하 피해가 없어요. 그 상태에서 점프하면 반대쪽으로 튕겨 올라가요.
- **로프 키:** X에서 C(또는 R)로 바뀌었어요.

## 6-2. 장기 성장 시스템 (로드맵 1차 반영)

### 랜덤 이벤트
탐험마다 마을 3개, 광산 4개가 무작위로 놓입니다. 최근에 자주 나온 이벤트는 덜 나옵니다. 가까이 가서 **↑** 키(모바일은 **조사** 버튼)를 누르면 선택창이 열립니다.

| 이벤트 | 구역 | 선택 |
|---|---|---|
| 버려진 보급실 | 전체 | 상자 3개와 박쥐 2마리 |
| 무너진 통로 | 전체 | 길이 돌로 막힘. 파서 뚫거나(돌 획득) 돌아가기 |
| 고대 제단 | 전체 | 하트 1 → 희귀 유물 / 버섯 2 → 희귀 자원 2 |
| 떠돌이 상인 | 전체 | 코인으로 버섯·물·기름·나무+돌·희귀 자원 구매 |
| 저주받은 상자 | 40m~ | 열면 유물+코인+희귀 자원, 대신 빛 −50과 괴물 4마리 |
| 잠긴 보물상자 | 광산 | 돌 4개로 부수면 유물+희귀 자원 |
| 맑은 샘 | 광산 | 목마름 가득 + 하트 +1 |

### 희귀 자원
- 바위 속에 반짝이는 광석이 있고, 캐면 얻습니다: **구리**(15–130m), **철**(95m~), **빛수정**(150m~).
- 몬스터를 잡으면 확률로 떨어집니다: **슬라임 젤**, **박쥐 날개**, **뼛조각**. 황금 슬라임과 보스는 확정으로 떨어뜨립니다.
- 쓰러져도 희귀 자원은 그대로 가지고 나옵니다.

### 지상 거점 (결과 화면 → 거점)
| 시설 | 효과 |
|---|---|
| 작업대 (Lv1~3) | 장비 제작. Lv3이 되면 장비 칸이 2개 |
| 연구실 (Lv0~3) | 영구 연구 6종 |
| 보관함 (Lv0~3) | 출발할 때 나무·물·버섯을 챙겨 감 |
| 전시실 (Lv0~3) | 코인 +5/10/15%, 유물 도감 바로가기 |

- **장비 6종:** 강화 곡괭이, 가죽 수통, 젤 장화, 확장 랜턴, 뼈 갑옷, 탐지기(가까운 보물·이벤트·광석 방향을 화살표로 표시). 한 번 만들면 계속 쓰고, 장착할 장비를 고릅니다.
- **연구 6종:** 버섯 재배, 물 거르기, 기름 정제(유물 8종 필요), 횃불 개량, 야영술, 몬스터 연구(몬스터 5종 발견 필요).
- 코인으로 사는 기존 업그레이드는 그대로 두고, 그와 별개인 성장 축으로 만들었습니다.

### 몬스터 도감 · 기록 · 도전 과제
- **몬스터 도감:** 7종(보스 2종 포함)입니다.
  - 아직 못 본 몬스터는 실루엣으로 나옵니다.
  - 처치 수, 처음 본 깊이, 공격 방식이 기록됩니다.
  - 드롭은 실제로 떨어진 것만 공개됩니다.
  - 7종을 모두 발견하면 150코인, 모두 처치하면 300코인을 한 번 받습니다.
- **기록:** 탐험 횟수, 최고 깊이, 탈출·쓰러짐 횟수, 총 생존 시간, 총 코인, 유물 수집률, 몬스터, 보스, 이벤트, 가장 많이 쓴 것.
- **도전 과제 13개:** 조건을 채우면 받기 버튼으로 코인을 받습니다. 과제 id는 나중에 Steam 업적으로 바로 연결할 수 있게 고정했습니다.

### 저장 안정성
- 저장 데이터에 버전(v2)을 붙였고, v1 저장은 자동으로 변환됩니다.
- 값이 잘못됐거나 일부가 빠진 저장도 살릴 수 있는 만큼 살립니다.
- 저장 데이터를 아예 읽을 수 없으면 `ruindiver.v1.broken`에 백업해 두고 새로 시작하며, 안내 문구를 띄웁니다.

### 밸런스 1차 조정 (`node tools/balance.mjs`)
- 실제 동굴 12개를 생성해서, 메인 경로 근처에 놓인 자원을 일정 비율만 줍는다고 가정하고 계산했습니다.
- 조정 전에는 업그레이드 없이 자원을 45%만 주워도 300m까지 갈 수 있었습니다. 생존 게이지가 아무 위협이 되지 않았습니다.
- 조정 내용: 자원 배치량 약 30~50% 감소, 배고픔 140초, 목마름 105초.
- 조정 후 결과:

| 업그레이드 단계 | 자원 30% 주울 때 | 45% | 60% |
|---|---|---|---|
| 업그레이드 없음 | 평균 217m | 평균 274m | 평균 294m |
| 초반 | 평균 266m | 평균 293m | 300m |
| 중반 이후 | 300m | 300m | 300m |

- 이 계산은 괴물과 보스로 인한 사망을 넣지 않은 것이라, 실제로는 더 빠듯합니다.

## 7. 기술 구성

- **엔진:** 이 저장소의 `pixelfx` 이펙트 라이브러리와 직접 작성한 플랫포머 물리·라이트맵입니다.
  - 픽셀 단위 조명을 Bayer 디더링으로 표현합니다.
- **빌드:** esbuild로 단일 HTML을 만듭니다. 이미지와 폰트는 HTML 안에 내장됩니다.
  - `dist/index.html`: Poki 업로드용
  - `dist/embed.html`: 아티팩트 미리보기용
  - 용량: 약 380KB
- **그래픽 (PixelLab, 2026-11-17):** 탐험가(걷기·대기·점프 애니메이션), 몬스터 5종, 보스 2종, 자원·상자·광석, 유물 31종·희귀 자원 6종 아이콘, 이벤트(제단·상인·샘), 흙·돌 지형 타일을 PixelLab으로 새로 그렸습니다. `art/px/atlas.png` 한 장(62KB)에 담겨 있고, 없는 그림은 예전 코드 스프라이트로 대신 그립니다. 무료 체험 40회 중 36회 사용.
- **그래픽 (이전):**
  - 타일·캐릭터·적·보스 스프라이트는 코드로 그린 픽셀아트입니다.
  - 배경 2장(`art/bg_village.png`, `art/bg_mine.png`)은 Scenario의 Retro Diffusion으로 생성했고, 패럴랙스로 표시됩니다.
- **폰트:** Galmuri11 Bold (OFL 라이선스). 빌드할 때 사용하는 글자만 남겨 용량을 줄입니다.
- **사운드:** WebAudio 합성 효과음 (먹기, 마시기, 설치, 상자, 밟기 콤보, 보스 등)
- **Poki SDK 래퍼 (`src/poki.js`):**
  - `gameplayStart` / `gameplayStop`, 광고 중간 휴식, 보상형 광고(부활)
  - Poki 밖에서 실행하면 대체 동작으로 넘어갑니다.
- **다국어:** 한국어 / 영어
- **저장:** localStorage에 코인, 최고 기록, 업그레이드, 도감, 세트, 보스 처치, 본 안내를 저장합니다.

## 10. 개발 히스토리

1. 구조 설계: 탐험 → 보상 → 탈출 → 수집 → 도감
2. Poki 방향 설정. 10초 내 첫 보상, 1~2분마다 업그레이드, 단순한 조작, "한 판만 더" 원칙 반영
3. 첫 프로토타입: 밧줄로 내려가는 방식
4. 진짜 동굴 탐험으로 전환: 옆에서 보는 플랫포머, 캐기, 탈출 or 사망
5. 픽셀아트 개선, 깊을수록 강해지는 보스
6. 초반 재미 개선
7. Scenario로 배경 아트 생성
8. **자원 관리 생존으로 재구성**
   - 배고픔·목마름·빛, 채집·제작 추가
   - 유물 가방 칸, 미션, 윈치, 대본식 튜토리얼 제거
9. **로드맵 1차 (현재):** 랜덤 이벤트, 희귀 자원과 장비, 지상 거점, 몬스터 도감, 기록·도전 과제, 저장 버전 관리, 생존 밸런스 시뮬레이션
