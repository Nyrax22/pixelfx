- 무너진 마을 아래 동굴을 탐험해 **300m 아래 출구**까지 살아서 내려가기

- 죽어도 모은 코인, 유물, 희귀 자원은 가지고 나옴 → 거점과 장비를 키워 더 깊이 내려가기

## 1-1. 핵심 루프: 더 내려갈까, 지금 나갈까
- **탈출 윈치**
  - 약 55m · 140m · 230m 부근에 있음
  - ↑를 누르면 들고 있는 보물을 전부 챙겨서 탐험을 끝냄
- **보물은 탈출해야 내 것**
  - 탈출 시 보물 가치 × (1 + 깊이/150) → 140m에서 나가면 ×1.9, 출구(296m)까지 가면 약 ×3
  - 쓰러지면 보물 가치의 25%만 남음
  - 주운 코인, 도감 등록, 희귀 자원은 그대로 유지
- **HUD 표시**
  - "보물 N · 탈출 ×k" 상시 표시
- **의뢰**
  - 탐험 전에 3개 중 하나 선택
  - 종류: 유물 찾기, 희귀 자원, 처치, 깊이, 비밀의 방, 석판, 항아리, 보물상자, 특정 깊이에서 탈출
  - 최고 기록에 따라 목표와 보상이 커짐
  - 완료하면 배너가 뜨고, 탐험이 끝날 때 보상 지급
- **보상 연출**
  - 희귀 이상 발견: 화면 멈춤 + "희귀한 발견!" 배너
  - 최고 기록을 넘는 순간: "최고 기록 갱신!" 배너
- **첫 탐험**
  - 시작 방에 보물상자 (10초 안에 첫 보상)
  - 처음 2번은 배고픔·목마름 없이 빛만 관리
- **생존 완화**
  - 배고픔 210초, 목마름 170초로 느려짐 (빛이 핵심 자원)
- **몬스터별 대응법**
  - 불꽃 해골: 돌진하다 벽에 부딪혀 기절했을 때만 공격 가능 (별이 돌며 깜빡임)
  - 붉은 슬라임: 앞에서는 곡괭이를 막음 → 밟거나 뒤를 노려야 함
- **업그레이드가 플레이를 바꿈**
  - 벽돌은 기본 곡괭이로 못 팜 → 폭탄이나 곡괭이 업그레이드(Lv2) 또는 강화 곡괭이가 필요
- **방 반복 방지**
  - 최근 4개 방 템플릿은 다시 나오지 않음
  - 선택형 방 추가: 썩은 발판 위 보물상자(아래는 가시), TNT 옆 벽돌 금고

## 2. 스테이지 (설계된 방)
- **구조**
  - 12×8칸 방을 가로 4칸 격자로 쌓아 만든 동굴
  - 길이 방을 따라 옆으로 이어지다가 사다리로 아래 방에 내려감
- **매번 다른 배치**
  - 칸 일부가 무작위로 바뀌고, 방마다 50% 확률로 좌우가 뒤집힘
- **길 방 14종**
  - 가시 구덩이, 화살 복도, 무너지는 다리, TNT 홀, 기둥 방, 금맥 방
  - 선반 방, 버섯 정원, 벽돌 선반, 몬스터 홀, 오두막, 화살·TNT 복합방
- **옆방 9종**
  - 벽돌로 막힌 금고, 황금 우상 방, 항아리 창고, 박쥐 굴, 금맥 바위
  - 화약 창고, 작은 샘, 무너진 통로, 화살 회랑
- **구역 2곳**
  - 무너진 마을 (0–100m)
  - 지하 광산 (100–300m)
- **보스 2마리**
  - 슬라임 킹 (88–98m): 뛰어올라 내려찍고 충격파를 보냄
  - 고대 골렘 (189–199m): 바닥을 내려치고 바위를 던짐
- **안전장치**
  - 생성 뒤 입구에서 출구까지 길이 이어지는지 검사하고, 막혔으면 통로를 뚫음

## 3. 조작
| 행동 | 키보드 | 모바일 |
|---|---|---|
| 이동 | ←→ / A D | 왼쪽 드래그 |
| 점프 / 벽차기 | Space / Z | 점프 버튼 |
| 사다리 | ↑↓ | 드래그 위아래 |
| 파기 | 벽으로 밀기, ↓ 길게 | 드래그 유지 |
| 곡괭이 공격 | X / J | 공격 버튼 |
| 폭탄 (↓와 함께 쓰면 발밑에 놓기) | B / V | 폭탄 버튼 |

## 4. 도구와 함정
- **곡괭이**
  - 파기와 공격에 사용
  - 내구도 30 (업그레이드로 증가)
  - 흙 1, 돌·벽돌 2씩 닳음
  - 보급 상자, 보물상자, 상인, 항아리에서 회복
- **폭탄**
  - 처음 3개, 1.6초 뒤 폭발
  - 벽(기반암 제외), 몬스터, 보스, 항아리를 날림
  - TNT는 연쇄 폭발, 나도 피해를 받음
  - 보급 상자(40%)와 상인에서 얻음
- **화살 함정**
  - 앞을 지나가면 철컥 소리 뒤 0.16초 만에 발사, 4초 뒤 재장전
  - 몬스터와 TNT도 맞음
- **무너지는 발판**
  - 밟으면 0.5초 뒤 떨어짐
- **황금 우상**
  - 가지면 코인이 쏟아지지만 거대한 바위가 굴러옴
- **TNT 통**
  - 공격, 화살, 폭발에 맞으면 잠시 뒤 터짐
- **그 밖의 위험**
  - 가시, 떨어지는 종유석, 낙하 피해

## 5. 생존
- **게이지 3개: 배고픔 · 목마름 · 빛**
  - 배고픔이나 목마름이 0이 되면 5초마다 하트가 하나씩 깎임
  - 빛이 줄면 화면이 어두워지고, 어둠 속에서는 괴물이 몰려옴
- **자원**
  - 버섯: 먹기. 모닥불 옆에서 먹으면 구워져 더 많이 참
  - 물웅덩이: 위에 서 있으면 물병이 참
  - 기름병: 빛 회복
  - 나무: 천장 뿌리, 보급 상자, 나무판자를 캐서 얻음
  - 돌: 돌·벽돌을 캐서 얻음
- **제작**
  - 횃불 (나무 2): 그 빛 안으로 괴물이 잘 들어오지 못함
  - 모닥불 (나무 3 + 돌 3): 체력 회복, 빛 충전, 버섯 굽기
  - 로프 (나무 2): 구덩이 탈출

## 6. 탐험
- **미지의 어둠**
  - 랜턴 빛이 직접 닿은 곳만 보이고, 벽 너머는 가 보기 전까지 검은색
- **미니맵**
  - 탐험한 곳만 그려짐
  - 보물상자, 이벤트, 석판, 봉인된 유물을 점으로 표시
- **비밀의 방**
  - 금 간 벽 틈에서 먼지가 새어 나옴
  - 금 간 벽은 내구도 소모 없이 금방 깨지고, 안에 보물과 석판이 있음
- **고대의 석판**
  - 이야기 조각 12개: 하람 마을이 가라앉은 이유, 심장석, 수호자 골렘, 맨 아래의 문
- **명소** (구역마다 하나씩)
  - 빛나는 버섯 동굴, 잊힌 묘지, 버려진 광부 야영지, 거대한 뼈 무덤, 수정 동굴
- **살아 있는 동굴**
  - 깨면 보상이 나오는 항아리
  - 빛나는 버섯과 수정, 덩굴, 거미, 해골, 광차, 화석
  - 도망 다니는 딱정벌레, 달팽이, 게, 도마뱀
- **랜덤 이벤트 7종** (마을 3개, 광산 4개, 최근에 나온 이벤트는 덜 나옴)
  - 보급실, 무너진 통로, 고대 제단, 떠돌이 상인, 저주받은 상자, 잠긴 보물상자, 맑은 샘
- **봉인된 유물** (선택)
  - 215m 아래에 있음
  - 꺼내면 보상이 2배가 되지만, 동굴이 무너지기 시작해 출구까지 달려야 함

## 7. 몬스터
| 몬스터 | 특징 | 드롭 |
|---|---|---|
| 동굴 박쥐 | 다가가면 날아옴, 빛을 싫어함 | 박쥐 날개 |
| 슬라임 | 바닥을 순찰 | 슬라임 젤 |
| 황금 슬라임 | 보면 도망감, 잡으면 코인 폭발 | 빛수정 |
| 붉은 슬라임 | 달려듦, 두 번 맞아야 쓰러짐 | 슬라임 젤 |
| 불꽃 해골 | 조준 후 돌진, 빛 속에선 돌진 안 함 | 뼛조각 |
| 슬라임 킹 (보스) | 점프 내려찍기, 충격파 | 슬라임 젤 ×4 |
| 고대 골렘 (보스) | 내려치기, 바위 던지기 | 철 ×3, 빛수정 ×3 |

- 공격 방법: 위에서 밟기, 곡괭이 공격, 폭탄, 화살 함정이나 바위로 유도

## 8. 장기 성장
- **코인 업그레이드**
  - 랜턴, 배낭, 체력, 곡괭이, 튼튼한 위장
- **희귀 자원 6종**
  - 광석: 구리, 철, 빛수정
  - 몬스터 드롭: 슬라임 젤, 박쥐 날개, 뼛조각
- **지상 거점**
  - 작업대 (Lv1–3): 장비 제작, Lv3에 장비 칸 2개
  - 연구실 (Lv0–3): 영구 연구
  - 보관함 (Lv0–3): 출발할 때 보급품
  - 전시실 (Lv0–3): 코인 보너스, 도감 바로가기
- **장비 6종**
  - 강화 곡괭이, 가죽 수통, 젤 장화, 확장 랜턴, 뼈 갑옷, 탐지기
- **연구 6종**
  - 버섯 재배, 물 거르기, 기름 정제, 횃불 개량, 야영술, 몬스터 연구
- **지름길 출발**
  - 보스를 쓰러뜨리면 그 보스 방에서 시작할 수 있음

## 11. 플랫폼과 기술
- **배포 형태**
  - 단일 HTML 파일, 약 650KB (그림·폰트 포함)
  - Netlify에 zip 하나로 올릴 수 있음
- **Poki SDK 연동 준비**
  - gameplayStart/Stop, 중간 광고, 보상형 광고(부활·코인 2배)
- **언어**
  - 한국어 / 영어
- **저장**
  - localStorage 저장, 버전 관리(v2)
  - 이전 저장 데이터 자동 변환, 손상되면 백업
- **입력 기기**
  - PC 키보드와 모바일 터치(가로 화면) 지원
- **코드 구조**
  - `src/rooms.js`: 방 템플릿
  - `src/cave.js`: 동굴 생성
  - `src/world.js`: 탐험 로직
  - `src/meta.js`: 장기 성장
  - `src/data.js`: 수치·문구
  - `src/main.js`: 화면·UI
