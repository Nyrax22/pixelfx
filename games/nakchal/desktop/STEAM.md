# 인생 떡상 — 스팀 출시 가이드

이 폴더는 웹 게임(`../index.html`)을 스팀에 올릴 수 있는 데스크톱 앱(Electron)으로 감싼 것이다.
게임 코드는 하나만 있고, 빌드할 때 `app/`으로 복사된다. 인터넷 없이 실행되도록
Three.js와 폰트를 CDN 대신 앱 안에 넣는다.

## 1. 실행·빌드 (내 컴퓨터에서)

```bash
cd games/nakchal/desktop
npm install            # 처음 한 번
npm start              # 데스크톱 창으로 실행 (전체화면, F11/Alt+Enter 창모드 전환)
npm run dist:win       # Windows 빌드 → dist/win-unpacked/
npm run dist:mac       # macOS 빌드 (맥에서 실행)
```

`dist/win-unpacked/` 폴더 전체가 스팀에 올릴 빌드다. 실행 파일은 `인생 떡상.exe`.

## 2. 스팀 쪽 준비 (사람이 직접 해야 하는 일)

1. **Steamworks 가입**: partner.steamgames.com → 앱 등록비(Steam Direct) $100 결제,
   세금·은행 정보 입력. 심사에 며칠 걸린다.
2. **App ID 받기** → `steam_appid.txt`의 `480`(테스트용 Spacewar)을 내 App ID로 바꾼다.
3. **업적 등록**: Steamworks → 통계 및 업적에서 아래 API 이름으로 23개를 만든다.
   게임에서 업적을 달성하면 자동으로 스팀 업적이 풀린다.

   | API 이름 | 이름 | 조건 |
   |---|---|---|
   | JOB1 | 첫 출근 | 알바 1번 |
   | JOB20 | 알바 장인 | 알바 20번 |
   | ACE | 에이스 | 알바 하나를 에이스로 |
   | JIN10 | 진상 면역 | 진상 손님 10명 |
   | PICK50 | 줍줍의 달인 | 길에서 50번 줍기 |
   | SCR20 | 긁는 손 | 즉석복권 20장 |
   | WON1 | 첫 낙찰 | 경매 낙찰 1번 |
   | WON10 | 경매왕 | 경매 낙찰 10번 |
   | TRADE20 | 개미 투자자 | 주식·코인 20번 |
   | LIMIT | 상한가 탑승 | 보유 종목 상한가 |
   | W500 | 500만원 | 순자산 500만원 |
   | W3000 | 3천만원 | 순자산 3천만원 |
   | W1E4 | 억대 자산가 | 순자산 1억 |
   | TIER1 | 반지하 탈출 | 옥탑방 이상 |
   | TIER3 | 아파트 입성 | 아파트 |
   | CAR | 오너 드라이버 | 첫 차 |
   | BIZ1 | 사장님 | 가게 1개 |
   | BIZ3 | 문어발 | 가게 3개 |
   | LV10 | 인생 레벨 10 | 레벨 10 |
   | MIS30 | 성실함 | 미션 30개 |
   | DAY30 | 한 달 생존 | 30일 |
   | HIT | 불사신 | 교통사고 생존 |
   | TOP | 랭킹 1위 | 부자 랭킹 1위 |

4. **업로드**: Steamworks SDK의 SteamPipe(ContentBuilder)로 `dist/win-unpacked/`를 올린다.
   실행 파일 경로는 `인생 떡상.exe`.
5. **스토어 페이지 이미지**: 캡슐 이미지(헤더 920×430, 소형 462×174, 메인 1232×706,
   세로 748×896, 라이브러리 600×900·3840×1240), 스크린샷 5장 이상, 트레일러(권장).
6. **AI 콘텐츠 공개**: 은행나무·포장마차 3D 모델은 AI(Higgsfield/Tripo)로 만들었다.
   Steamworks의 "AI 생성 콘텐츠 공개" 설문에 "사전 생성된 콘텐츠"로 적어야 한다.
7. **라이선스 확인**: 위 AI 모델은 Higgsfield **무료 플랜**으로 만들었다.
   판매용으로 쓰려면 그 플랜이 상업적 이용을 허락하는지 Higgsfield 약관에서 확인하고,
   필요하면 유료 플랜에서 다시 생성한다. 그 밖의 에셋(Poly Haven CC0, Three.js MIT,
   폰트 OFL)은 상업적 이용이 가능하다 — `../assets/CREDITS.txt` 참고.
8. 출시 2주 전에 "출시 예정" 페이지를 공개해야 하고, 빌드·스토어 심사를 통과해야 출시 버튼이 열린다.

## 3. 데스크톱 판에서 달라지는 점

- 전체화면으로 시작, F11 / Alt+Enter로 창모드 전환
- 타이틀과 설정(Esc)에 "게임 종료" 버튼 (종료 전에 자동 저장)
- 저장은 앱 전용 저장소에 남는다 (브라우저와 별개)
- 스팀이 켜져 있으면 업적·오버레이(Shift+Tab) 동작, 없으면 그냥 오프라인으로 실행
